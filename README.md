# Padel Dashboard

Мобильное веб-приложение для игры в падел компанией: строит очерёдность игр на одном или нескольких кортах и ведёт турнирную таблицу.

**Открыть:** https://pdmulenko.github.io/padel-dashboard/

- Режимы: американо (личный зачёт) и фиксированные пары («по кругу» или «победитель остаётся»).
- Один или несколько кортов, свободный счёт или фиксированная сумма очков.
- Окончание турнира по числу туров или кругов, итоги с победителем.
- Работает без интернета (service worker) и без сборки, данные хранятся в браузере. Русский и английский, светлая и тёмная тема.

Подробное описание — в [SPEC.md](SPEC.md).

## Разработка

Чистый HTML, CSS и JavaScript-модули, без зависимостей.

```bash
python3 -m http.server 8000   # затем открыть http://localhost:8000
npm test                      # тесты расписания, подсчёта и хранения (node --test)
npm run sw-version            # перед выкладкой: обновить отпечаток версии в sw.js
```

После любых правок файлов приложения перед коммитом нужен `npm run sw-version` — иначе телефоны не узнают об обновлении (тест об этом напомнит).
